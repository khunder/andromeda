🚀 BPMN Designer - Deployment Test

New Features Added:

✅ Configuration Panel: Click the ⚙️ button to configure engine URL (default: http://localhost:5000)

✅ Deployment Panel: Shows when nothing is selected - enter deployment ID and deploy

✅ Deploy Button: Click 🚀 Deploy in toolbar to deploy BPMN to Andromeda engine

✅ Multipart Form Upload: BPMN XML is sent as multipart/form-data with deployment ID

How to Test:

  1. Open the main application at index.html
  2. Click the ⚙️ (settings) button in the toolbar
  3. Configure your Andromeda engine URL (default: http://localhost:5000)
  4. Optionally set a default deployment ID
  5. Click "Test Connection" to verify the engine is reachable
  6. Save the configuration
  7. Create a BPMN diagram using the palette
  8. Click on empty canvas to see the deployment panel
  9. Enter a deployment ID (e.g., "my-process-v1")
  10. Click "🚀 Deploy to Engine" button

⚠️ Prerequisites:

1. Ensure your Andromeda engine is running at the configured URL

2. The engine should have the /api/compile endpoint available

3. CORS should be enabled on the engine for browser requests

4. The engine should accept multipart/form-data with fields: bpmnFile and deploymentId
